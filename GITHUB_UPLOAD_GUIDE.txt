
==========================================================
 ЗАЛИТИ CNC_Comb_STM32 НА GITHUB — 4 КРОКИ (3 хвилини)
==========================================================

Папка: цей же каталог, де лежить platformio.ini
Вкладка у провіднику Windows: ...\Arduino\CNC_Controler\CNC_Comb_STM32


----------[ КРОК 1/4 ]----------
Спочатку двічі клацни на файл:

    01_setup_github_author.bat

    (Якщо Windows блокує — More info → Run anyway. Безпечний batch-файл.)

Скрипт попросить 2 речі. Введи і натисни Enter після кожного:

    1. Логін на GitHub.      Приклад: z-book
       (Візьми з https://github.com/ — вгорі праворуч)

    2. VERIFIED email.      Приклад: 123456+z-book@users.noreply.github.com
       (Відкрий https://github.com/settings/emails
        і скопіюй email з галочкою Verified
         АБО візьми той, що на noreply.github.com  — він завжди є).

Дочекайся напису [ГОТОВО] і натисни Enter.


----------[ КРОК 2/4 ]----------
Відкрий в браузері: https://github.com/new

Заповни так:
  Repository name:  CNC_Comb_STM32
  Private:            ✅ (рекомендовано, поки не протестовано)

  ⚠️  3 галочки НЕ ВІДМІЧАТИ:
       [ ] Add a README file
       [ ] Add .gitignore
       [ ] Choose a license

Натисни зелену кнопку [Create repository].


----------[ КРОК 3/4 ]----------
Після натискання ти потрапиш на сторінку "Quick setup".
Праворуч від URL-рядка є КНОПКА-КОПІЮВАННЯ (два квадратики).
Натисни її.

URL у буфері виглядає так:
    https://github.com/z-book/CNC_Comb_STM32.git
    (тут z-book — ТВОЙ логін, не мій)


----------[ КРОК 4/4 ]----------
Повернись у папку, двічі клацни:

    02_push_to_github.bat

Він попросить URL. Праворуч у вікні консолі:
  Праву кнопку миші → Paste (або просто клікнути правою — Win10 вставляє).

Натисни Enter.

З'явиться віконце GitHub CLI — натисни "Sign in with your browser",
введи пароль, дозволь доступ.

Чекай поки з'явиться:
  ================= [ГОТОВО!] =================


==========================================================
 ПІСЛЯ ЗАЛИВКИ — ЧИ ПРАЦЮЄ?
==========================================================

1. У браузері онови сторінку github.com/.../CNC_Comb_STM32
   Ти маєш бачити:
      ▶ include/
      ▶ src/
      .gitattributes
      .gitignore
      platformio.ini
      01_setup_github_author.bat
      02_push_to_github.bat
      ЦЕЙ_ФАЙЛ.txt

2. Клацни src/main.cpp — має відкритися код.

3. Перейди в вкладку Insights → Network — має бути 1 точка = 1 коміт.
   Якщо навпроти коміту ЗЕЛЕНИЙ КВАДРАТИК і твій аватар
   — все, авторство працює.


==========================================================
 ЩО РОБИТИ, ЯКЩО ЩОСЬ НЕ ТАК? (Часті проблеми)
==========================================================

❓ Крок 1 вікно закрилося, не встиг ввести.
   → Перезапусти 01_setup_github_author.bat.

❓ Крок 3 не можу знайти email verified.
   → Відкрий https://github.com/settings/emails
     → под галочкою "Keep my email addresses private"
       буде рядок: "...+login@users.noreply.github.com"
     → скопіюй його.

❓ Крок 4: помилка "Repository not found" / 403.
   → Ти ВСТАВИВ НЕ ТОЙ URL. Перейди на github/new,
     створюй новий (на 100% без галочок).
     Новий репо = новий URL.

❓ Зелений квадратик навколо коміту немає.
   → Значить, email у коміті НЕ співпадає з Verified.
     Запусти знову 01_setup_github_author.bat
     (вкажи ТОЧНО той email, як у Settings → Emails).
     Потім 02_push_to_github.bat (новий amend).


==========================================================
 НАСТУПНІ РАЗИ — КОЛИ ЗМІНИШ КОД
==========================================================

Просто зроби 3 команди в Git Bash / PowerShell, або
зроби ще один .bat (03_commit_and_push.bat) з вмістом:

    @echo off
    cd /d "%~dp0"
    git add -A
    git commit -m "описи змину одним реченням"
    git push
    pause

Готово.
